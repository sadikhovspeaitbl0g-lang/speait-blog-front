# The history
Both of those protocols run on application layers in both the OSI and TCP/IP protocol suites. 

[OSI vs TCP](https://media.geeksforgeeks.org/wp-content/uploads/20230417045622/OSI-vs-TCP-vs-Hybrid-2.webp)

(Fun fact: many people argue of whether the HTTPS protocols runs on application layer, because it also provides the encryption and the session establishment between a client and a web server, thus many people consider it more reasonable to assign it to presentation or session layers)

HTTP (Hypertext Transfer Protocol) was developed between 1989 and 1991 by Tim Berners-Lee at CERN, with the initial early version (HTTP/0.9) coming into use around 1991.
